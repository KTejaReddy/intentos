# IntentOS Changelog

## [1.0.0-rc.1] - 2026-08-05

### Added
- **RC-1 Demonstration Collateral**: `PITCH.md`, `ROADMAP.md`, `KNOWN_LIMITATIONS.md`, and `DEMO_CHECKLIST.md`.
- **Pipeline Visualizer**: Real-time inspection of Lexer tokens, AST nodes, and memory footprints in the IDE.
- **Glassmorphism UI**: High-end UI aesthetics matching Cursor/Linear using translucent backgrounds and gradients.

### Changed
- **Pipeline Fault Tolerance**: AI generation failures in `pipeline.py` now raise strict runtime exceptions rather than falling back to heuristics silently.
- **Docker Generation**: Replaced hardcoded default credentials with strict `.env` variable interpolation (`${POSTGRES_PASSWORD}`).
- **Backend Generators**: Enforced explicit `.env` configurations for `INTENTOS_SECRET` and database passwords in FastAPI and Spring Boot targets.

### Fixed
- **API Stubs**: Non-CRUD API routes generated by the FastAPI backend now correctly raise `501 Not Implemented` rather than silently returning empty bodies.
- **Generator Enforcement**: Replaced `NotImplementedError` with `@abc.abstractmethod` in the base generator to fail explicitly at import time for incomplete targets.
- **Path Traversal Vulnerability**: Secured `workspace.py` read/write operations using `pathlib.is_relative_to`.
